# ♥ Приглашение на свидание

Небольшой интерактивный сайт-приглашение: вступление → вопрос «Ты хочешь пойти со мной на свидание?» → выбор дня в октябре 2026 → выбор времени → подтверждение.

Сделан на **React + Vite**, без сервера. Публикуется на **GitHub Pages** как обычный статический сайт.

---

## Быстрый старт

Нужен установленный [Node.js](https://nodejs.org) версии 18 или новее (лучше 20 LTS).

```bash
npm install      # установить зависимости (один раз)
npm run dev      # запустить локально → откройте адрес из терминала, обычно http://localhost:5173
npm run build    # собрать готовый сайт в папку dist/
npm run preview  # посмотреть собранную версию локально
```

Чтобы открыть сайт с телефона в той же Wi‑Fi сети: `npm run dev -- --host` и откройте на телефоне адрес `Network: http://192.168.…`.

## Где что менять

| Что | Файл |
|---|---|
| **Все тексты** (вопросы, кнопки, забавные фразы после «Нет») | `src/content.js` → объект `content` |
| Месяц календаря и список времени | `src/content.js` → объект `schedule` |
| Цвета, шрифты, скругления, тени | `src/styles.css` → блок `:root` в начале |
| Сохранение выбора | `src/lib/booking.js` |
| Заголовок вкладки и превью ссылки в мессенджерах | `index.html` |

Фразы после нажатия «Нет» идут по порядку из массива `noReactions`. Когда они закончатся, следующее «Нет» засчитывается по-настоящему и показывается мягкий экран «Хорошо, я понял» с кнопкой «Подожди, я передумала». То есть отказать технически можно всегда.

## Сохранение выбора и его ограничение

После нажатия «Готово» выбор сохраняется в **localStorage** браузера в виде:

```json
{ "date": "2026-10-15", "time": "19:00" }
```

При повторном открытии сайт сразу показывает экран подтверждения. Кнопка «Выбрать другое время» возвращает к календарю, новый выбор перезаписывает старый.

> ⚠️ **Важно:** localStorage хранит данные **только в браузере того, кто выбирал**.
> - Вы (автор) **не увидите** выбранную дату у себя — попросите прислать скриншот экрана подтверждения или файл календаря (кнопка «Добавить в календарь»).
> - Если открыть сайт на другом телефоне или в другом браузере, выбор там не появится.
> - Если нужно, чтобы выбранное время действительно становилось занятым для других или приходило вам, нужен backend / база данных.

### Как подключить базу данных позже

Весь код работает только через три функции из `src/lib/booking.js`: `saveBooking()`, `getBooking()`, `clearBooking()`. Они уже асинхронные. Чтобы перейти на базу (Firebase, Supabase, свой API, Google Forms и т. п.):

1. Напишите новый адаптер с методами `get`, `save`, `clear` — пример `apiAdapter` уже есть в файле в комментарии.
2. Замените строку `const adapter = localStorageAdapter;` на свой адаптер.

Компоненты менять не придётся.

## Публикация на GitHub Pages

В проект уже добавлена автоматическая публикация (`.github/workflows/deploy.yml`): при каждом push в ветку `main` GitHub выполняет `npm install` → `npm run build` и публикует папку `dist`.

Путь сайта уже настроен в `vite.config.js` под репозиторий **`date-invitation`**: при сборке `base` = `/date-invitation/`, при локальном `npm run dev` — `/`. Если назовёте репозиторий иначе, поменяйте константу `REPO_NAME` в `vite.config.js`, иначе страница откроется пустой.

### 1. Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Справа вверху **+ → New repository**.
3. Имя — **`date-invitation`** (именно так, под него настроен `base`).
4. Видимость **Public** (на бесплатном тарифе Pages работает только для публичных репозиториев).
5. Галочки README / .gitignore **не** ставьте. Нажмите **Create repository**.

### 2. Установите зависимости и проверьте сборку

В папке проекта:

```bash
npm install
npm run build
```

`npm install` создаст файл `package-lock.json` — его стоит загрузить в репозиторий вместе с проектом, чтобы на GitHub ставились те же версии пакетов, что у вас.

### 3. Загрузите проект

Вариант А — через терминал (нужен установленный [Git](https://git-scm.com)):

```bash
git init
git add .
git commit -m "Приглашение на свидание"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/date-invitation.git
git push -u origin main
```

Вариант Б — без терминала: на странице пустого репозитория нажмите **uploading an existing file** и перетащите содержимое папки проекта (кроме `node_modules` и `dist`). Папка `.github` скрытая — в macOS покажите скрытые файлы сочетанием `Cmd + Shift + .`, в Windows включите «Скрытые элементы» во вкладке «Вид». Проще и надёжнее — [GitHub Desktop](https://desktop.github.com).

### 4. Включите GitHub Pages

1. В репозитории: **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions**: там запустится «Deploy to GitHub Pages». Если он уже упал до включения Pages — нажмите на него и **Re-run all jobs**.
4. Через 1–2 минуты появится зелёная галочка.

### 5. Получите адрес сайта

Адрес будет таким:

```
https://ВАШ_ЛОГИН.github.io/date-invitation/
```

Он же показан в **Settings → Pages** и в результате запуска на вкладке **Actions**. Эту ссылку и отправляйте ♥

### Дальнейшие изменения

Поменяли текст в `src/content.js` → `git add . && git commit -m "текст" && git push` → через минуту сайт обновится.

### Альтернатива: публикация одной командой (без Actions)

```bash
npm run deploy
```

Команда соберёт сайт и выложит его в ветку `gh-pages`. Затем в **Settings → Pages → Source** выберите **Deploy from a branch**, ветку `gh-pages`, папку `/ (root)`.

## Полезно знать

- Чтобы протестировать сайт «с нуля», сотрите сохранённый выбор: в браузере откройте DevTools → Application → Local Storage → удалите `date-invitation:booking`. Или откройте сайт в режиме инкогнито.
- Прошедшие дни октября в календаре автоматически становятся неактивными.
- Если на телефоне включено «Уменьшение движения», анимации отключаются.
